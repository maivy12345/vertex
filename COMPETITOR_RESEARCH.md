# Vertex website — competitor content review

Reviewed 2 October 2026. This is an editorial reference for the site, not copy for publication.

| Comparator | What its public site makes clear | Implication for Vertex |
| --- | --- | --- |
| [Turner & Townsend — Project management](https://www.turnerandtownsend.com/en-us/what-we-do/services/project-management/) | Separates project, programme, portfolio and PMO services; describes the governance and information each provides. | Explain how Vertex's six control disciplines connect, and name tangible working outputs. |
| [Mace Consult — MTR](https://www.macegroup.com/en-us/projects/mtr/) | Shows integrated PMO, planning, cost, risk and digital reporting in a specific rail context, supported by a named client and figures. | Give visitors a concrete decision pathway. Use an explicitly illustrative scenario until Vertex has approved client evidence. |
| [Arcadis — Project and program management](https://www.arcadis.com/en/services/program-management/project-program-management) | Links advisory, digital intelligence and delivery, with an emphasis on earlier evidence-based decisions. | Move the story beyond dashboards to cause, exposure, options, ownership and action. |
| [AtkinsRéalis — Project controls](https://careers.atkinsrealis.com/en/our-job-areas/project-and-programme-management/uk-project-and-programme-services) | Describes planning, cost, risk and change as one control system and ties them to forecasting and performance data. | Make the baseline → performance → forecast → decision logic visible. |

## Changes informed by the review

- Home: added entry points for mobilisation, recovering visibility and time-sensitive decisions, plus an illustrative decision pathway.
- Expertise: added example working outputs, an integrated controls flow and common questions.
- Approach: added a practical starting sequence with example outputs.
- Sectors: added a concise control focus for each infrastructure context.
- Layout: added varied editorial grids, a structured decision panel, concise tags and responsive treatments for small screens.

## Evidence still needed before publishing stronger proof

Named client examples, measured outcomes, testimonials, team credentials and proprietary tool claims should only be added after Vertex provides approved source material. None were invented for this revision.
